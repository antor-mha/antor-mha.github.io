# antor-mha.github.io

Personal portfolio of Mehedi Hasan Antor. Plain HTML and CSS, no build step, hosted on GitHub Pages.

## Structure
- `index.html`, `projects.html`, `404.html`
- `assets/` for `style.css`, `main.js` and `og.png` (add a 1200x630 preview image)
- `favicon.svg`, `sitemap.xml`, `robots.txt`

## Updating
Edit the HTML and push to `main`. Add new pages to `sitemap.xml`.
